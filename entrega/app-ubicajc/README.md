# UbicaJC

Prototipo académico de un sistema de ubicación y trazabilidad de tarimas para las cámaras frigoríficas de Carnes JC.
Propuesta del equipo del Instituto Tecnológico de Hermosillo (TecNM) para el reto "Gestión y Administración de Inventarios"
del programa Jóvenes Impulsando la Industria 2026.

**Todos los datos son simulados.** No es un sistema oficial de Carnes JC. El nombre UbicaJC es una propuesta; la marca JC pertenece a Carnes JC.

## Qué incluye

- Mapa de las 6 cámaras (plano 2D y vista 3D) con semáforo de caducidad.
- Acomodo con asignación sugerida (tipo de cámara, espacio libre y FEFO).
- Búsqueda por producto, lote o etiqueta master.
- Surtido y reubicación con doble escaneo (ubicación + master).
- Reporte de "no encontrado" que genera un conteo cíclico.
- Bitácora de movimientos por lote, indicadores y simulación de caída de internet.

## Cómo usarlo

Es un solo archivo, `index.html`, sin dependencias ni instalación. Ábrelo en cualquier navegador.

Para publicarlo con GitHub Pages: en el repositorio ve a **Settings → Pages**, elige **Deploy from a branch**,
la rama `main` y la carpeta `/ (root)`, y guarda. En un par de minutos queda disponible en
`https://<usuario>.github.io/<repositorio>/`.
